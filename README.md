# South Hills Soft Wash Website

A custom responsive website designed and developed for South Hills Soft Wash, a family owned exterior cleaning company serving the South Hills and surrounding Pennsylvania communities.

This project replaced the company's previous Google Sites website with a fully custom website built using Astro.

## About the Project

I designed and developed this website from the ground up for South Hills Soft Wash, working directly with the business owners throughout the design and development process.

The goal was to create a modern, responsive website that better represents the company's brand, clearly organizes its residential and commercial services, and provides customers with an easy way to explore previous work and request a quote.

## Built With

- Git & GitHub

## Features

- Fully responsive desktop, tablet, and mobile design
- Custom navigation with service dropdowns and mobile menu
- Residential and commercial service pages
- Before-and-after project gallery
- Interactive service-area map
- JotForm quote request integration
- Custom branded mascot integration
- Responsive animations and hover interactions
- Search engine optimized page titles and descriptions
- Canonical URLs and social sharing metadata
- XML sitemap and robots.txt
- LocalBusiness structured data
- Custom domain and HTTPS deployment

## SEO
